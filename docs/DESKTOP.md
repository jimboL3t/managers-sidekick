# Έκδοση 1.4.0 — τοπική δοκιμή desktop πακέτων

[English](DESKTOP.en.md)

Ο κώδικας της 1.4.0 προορίζεται για review. Δεν έχει δημοσιευτεί release με τα νέα EXE/DMG. Η δημόσια έκδοση 1.3.0 παραμένει διαθέσιμη.

## Windows 64-bit: portable με εικονίδιο

1. Αποσυμπιέστε **ολόκληρο** το `managers-sidekick-1.4.0-windows-x64.zip` σε φάκελο όπου έχετε δικαίωμα εγγραφής, π.χ. Documents.
2. Ανοίξτε το **managersSidekick.exe**, με το εικονίδιο MS. Μπορείτε να δημιουργήσετε συντόμευση στην επιφάνεια εργασίας.
3. Δεν χρειάζεται εγκατάσταση Java ή installer. Το EXE χρειάζεται το JAR και τον φάκελο `runtime` δίπλα του: μην το μετακινείτε μόνο του.

Τα δεδομένα αποθηκεύονται στον `data/sidekick.json` **δίπλα στο EXE**, ανεξάρτητα από τον φάκελο εκκίνησης της συντόμευσης. Για ενημέρωση, κλείστε την εφαρμογή, κρατήστε αντίγραφο του παλιού `data`, αποσυμπιέστε τη νέα έκδοση σε ξεχωριστό φάκελο και αντιγράψτε ολόκληρο τον παλιό `data` εκεί **πριν την πρώτη εκκίνηση**. Κρατήστε τον παλιό φάκελο μέχρι να επιβεβαιώσετε τα δεδομένα.

## macOS: DMG και Applications

Ανοίξτε το DMG για την αρχιτεκτονική του Mac σας και σύρετε το `ManagersSidekick.app` στο Applications. Κατόπιν ανοίξτε την εφαρμογή από το Applications. Το τοπικό build παράγει DMG για την αρχιτεκτονική του υπολογιστή που το κατασκευάζει: Apple Silicon (arm64) ή Intel (x64).

Η Java περιλαμβάνεται. Τα δεδομένα βρίσκονται στο **`~/ManagersSidekick/data/sidekick.json`**, δηλαδή μέσα στον προσωπικό φάκελο χρήστη, έξω από την εφαρμογή. Στο Finder → Go → Go to Folder μπορείτε να δώσετε `~/ManagersSidekick/data`.

Για επόμενη ενημέρωση, κλείστε την εφαρμογή, κρατήστε αντίγραφο του `data` και αντικαταστήστε μόνο το `.app` στο Applications. Το υπάρχον JSON παραμένει στον ίδιο φάκελο και φορτώνεται ξανά. Μην ανοίγετε ταυτόχρονα δύο εκδόσεις που χρησιμοποιούν την ίδια βάση.

### Πρώτη μεταφορά από το παλιό portable Mac πακέτο

1. Κλείστε και τις δύο εκδόσεις.
2. Αντιγράψτε τον παλιό φάκελο `data` σε ασφαλές σημείο ως backup.
3. Αν δεν υπάρχουν ήδη δεδομένα στο `~/ManagersSidekick/data`, αντιγράψτε εκεί τον παλιό `data`, μαζί με το `sidekick.json`.
4. Αν υπάρχουν ήδη δεδομένα στον προορισμό, κρατήστε ξεχωριστό backup και επιλέξτε ποια βάση θέλετε να διατηρήσετε. **Δεν γίνεται συγχώνευση**· μην αντικαταστήσετε μια βάση χωρίς να κρατήσετε αντίγραφο.
5. Ανοίξτε τη νέα εφαρμογή και ελέγξτε ομάδες, μήνες και ιστορικό. Ο παλιός φάκελος δεν διαγράφεται αυτόματα.

## Backup και επαναφορά

Με κλειστή την εφαρμογή, αντιγράψτε ολόκληρο τον ενεργό φάκελο `data` σε άλλο δίσκο/φάκελο με ημερομηνία. Για επαναφορά, κλείστε την εφαρμογή και επαναφέρετε το αντίγραφο στον ίδιο προορισμό. Το αυτόματο `sidekick.json.bak` της προηγούμενης αποθήκευσης δεν αντικαθιστά ανεξάρτητα backups. Τα προσωπικά δεδομένα δεν περιλαμβάνονται στα πακέτα διανομής.

Τα δοκιμαστικά πακέτα δεν διαθέτουν πιστοποιητικό υπογραφής Windows ή Apple notarization. Το λειτουργικό ενδέχεται να ζητήσει έγκριση κατά την πρώτη εκκίνηση. Δεν απαιτείται απενεργοποίηση των προστασιών του συστήματος.

## Κατασκευή και έλεγχος

Σε macOS με JDK, Maven, Python 3.12+ και MinGW (`brew install mingw-w64`):

```sh
python3 scripts/package_desktop.py
```

Χρησιμοποιεί τα ήδη επαληθευμένα runtime/source archives του `dist/release-cache`, εκτελεί τα Java tests και δημιουργεί `dist/desktop-review-1.4.0`. Δεν κάνει commit, upload ή αλλαγή ιστοσελίδας. Για Intel DMG εκτελείται σε Intel Mac. Η Java των πακέτων είναι αυτή του `packaging/runtime-lock.json`, όχι η Java του συστήματος κατασκευής. Το πακέτο πηγών πρέπει να συνοδεύει μελλοντική δημόσια διανομή.

Για αποδοχή στα Windows χρειάζεται πραγματική δοκιμή του EXE: εκκίνηση, αποθήκευση, επανεκκίνηση, εξαγωγή PDF και συντόμευση από διαφορετικό φάκελο. Ο έλεγχος αρχείου EXE σε Mac δεν ισοδυναμεί με εκτέλεση στα Windows.
