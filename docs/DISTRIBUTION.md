# Διανομή και δοκιμή σε Windows / Linux — 0.9.0

## Τι στέλνουμε

Στείλτε το `dist/managers-sidekick-0.9.0-test.zip` και προαιρετικά το διπλανό `.sha256`. Το ίδιο ZIP χρησιμοποιείται σε Windows και Linux. Περιλαμβάνει εκτελέσιμο JAR με τις βιβλιοθήκες του, scripts εκκίνησης, εγχειρίδια και άδειες βιβλιοθηκών. Δεν περιλαμβάνει Java, προσωπικά δεδομένα, Maven cache, Git ή ρυθμίσεις IDE.

Αυτό είναι φορητό πακέτο δοκιμής που απαιτεί εγκατεστημένη Java, όχι installer `.exe`/`.deb` με ενσωματωμένο runtime. Η έκδοση εφαρμογής παραμένει 0.9.0.

## Απαιτήσεις ανά λειτουργικό

| Λειτουργικό | Τι εγκαθιστά ο δοκιμαστής | Εκκίνηση |
|---|---|---|
| Windows με γραφικό desktop | Java 21+ πλήρες JRE ή JDK, αντίστοιχο της CPU· προτεινόμενο Temurin 21. Arial με ελληνικά για PDF. | `start-windows.cmd` |
| Linux με γραφικό desktop | Java 21+ με Swing/AWT (`java.desktop`), όχι μόνο headless runtime. DejaVu Sans για PDF. | `sh start-linux.sh` |
| macOS (προαιρετική ίδια διανομή) | Java 21+ για Apple Silicon ή Intel, ανάλογα με το Mac. Arial για PDF. | `sh start-linux.sh` από Terminal |

Δεν χρειάζονται Maven, Git, Python, IDE, βάση δεδομένων ή server στους υπολογιστές δοκιμής. Μετά την εγκατάσταση Java και γραμματοσειράς η εφαρμογή λειτουργεί χωρίς σύνδεση Internet. Χρειάζεται δικαίωμα εγγραφής στον αποσυμπιεσμένο φάκελο. Το JAR είναι κοινό, αλλά η εγκατάσταση Java πρέπει να αντιστοιχεί στο OS και στην αρχιτεκτονική του υπολογιστή.

## Windows

1. Κατεβάστε **Temurin 21**, τύπου **JRE** ή **JDK**, για το Windows/CPU σας από τις [επίσημες εκδόσεις Adoptium](https://adoptium.net/temurin/releases/?version=21). Για συνήθη Windows x64 χρησιμοποιήστε το MSI. Στο installer κρατήστε ενεργό το **Add to PATH**· προαιρετικά ενεργοποιήστε το `JAVA_HOME`. Δείτε τον [επίσημο οδηγό MSI](https://adoptium.net/installation/windows/).
2. Ανοίξτε νέο Command Prompt και εκτελέστε `java -version`. Η κύρια έκδοση πρέπει να είναι τουλάχιστον 21. Οι Java 8/11/17 δεν αρκούν.
3. Κάντε **Extract All** του ZIP, π.χ. στα Documents, σε δικό του φάκελο. Αποφύγετε το `Program Files`, όπου συνήθως δεν υπάρχει δικαίωμα εγγραφής για τα δεδομένα.
4. Ανοίξτε το `start-windows.cmd` με διπλό κλικ. Σε αποτυχία κρατά το terminal ανοιχτό για να διαβάσετε το μήνυμα.

Το script χρησιμοποιεί το `JAVA_HOME\bin\java.exe`, εφόσον υπάρχει, αλλιώς το `java` του PATH. Αν υπάρχει παλιό JAVA_HOME, διορθώστε το ώστε να δείχνει στη σωστή εγκατάσταση. Για Windows ARM επιλέξτε runtime που υποστηρίζει το συγκεκριμένο σύστημα· ο παραπάνω MSI οδηγός αφορά x64.

## Linux

Χρειάζεται κανονική συνεδρία γραφικού desktop. Ένα SSH terminal χωρίς display ή ένας headless server δεν αρκεί για το Swing GUI.

Για **Ubuntu 24.04**, από terminal:

```sh
sudo apt update
sudo apt install openjdk-21-jre fonts-dejavu-core
java -version
```

Εγκαταστήστε το πλήρες `openjdk-21-jre`, όχι μόνο `openjdk-21-jre-headless`. Σε άλλη διανομή/έκδοση τα ονόματα και η διαθεσιμότητα πακέτων διαφέρουν: χρησιμοποιήστε το πακέτο desktop Java 21+ της διανομής ή τον [επίσημο οδηγό Temurin για Linux](https://adoptium.net/installation/linux/). Για χειροκίνητο archive, επιλέξτε το σωστό OS/CPU από τις [εκδόσεις Temurin](https://adoptium.net/temurin/releases/?version=21) και εγκαταστήστε τις απαιτούμενες βιβλιοθήκες desktop της διανομής.

Αποσυμπιέστε το ZIP από τον file manager. Μέσα στον αποσυμπιεσμένο φάκελο:

```sh
sh start-linux.sh
```

Εναλλακτικά: `chmod +x start-linux.sh` και `./start-linux.sh`. Δεν χρειάζεται `sudo` για την εφαρμογή. Το script χρησιμοποιεί πρώτα έγκυρο `JAVA_HOME/bin/java`, αλλιώς το Java του PATH.

## Ελληνικά και PDF

Το PDF αναζητά Arial στα Windows/macOS και DejaVu Sans στο Linux. Σε Linux η προεπιλεγμένη διαδρομή είναι `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf`. Αν η διανομή τοποθετεί τη γραμματοσειρά αλλού ή εμφανίζεται μήνυμα ότι δεν βρέθηκε, δώστε αρχείο TrueType με ελληνικά:

Linux:

```sh
SIDEKICK_FONT="/absolute/path/DejaVuSans.ttf" sh start-linux.sh
```

Windows Command Prompt:

```bat
set "SIDEKICK_FONT=C:\Fonts\GreekFont.ttf"
start-windows.cmd
```

Δεν απαιτείται ξεχωριστή εγκατάσταση PDFBox/Gson: βρίσκονται ήδη στο JAR. Η πραγματική εκτύπωση γίνεται ανοίγοντας το PDF σε viewer.

## Μεταφορά δεδομένων και αναβάθμιση

Η πρώτη εκτέλεση αρχίζει με κενή λίστα ομάδων. Αν θέλετε να δοκιμάσετε τα δικά σας δεδομένα:

1. Κλείστε την εφαρμογή στον αρχικό υπολογιστή και κρατήστε backup του φακέλου `data`.
2. Αντιγράψτε **αντίγραφο** του `data` δίπλα στο `managers-sidekick.jar` στον υπολογιστή δοκιμής. Μην αντικαταστήσετε υπάρχοντα δεδομένα του δοκιμαστή χωρίς πρώτα backup.
3. Ανοίξτε το πρόγραμμα. Οι ομάδες και οι μήνες φορτώνονται τοπικά. Δεν υπάρχει συγχρονισμός με τον αρχικό υπολογιστή.

Μπορείτε να χρησιμοποιήσετε «Αντίγραφο για δοκιμές» και μέσα στην εφαρμογή. Κάθε εκτέλεση χρησιμοποιεί τα δεδομένα του συγκεκριμένου φακέλου. Μην ανοίγετε δύο instances πάνω στον ίδιο φάκελο δεδομένων.

Για μελλοντική έκδοση, αποσυμπιέστε σε νέο φάκελο και μεταφέρετε αντίγραφο του `data` με κλειστή εφαρμογή. Ο φάκελος `data` δεν είναι μέσα στο ZIP και δεν διαγράφεται από το script πακεταρίσματος.

## Συχνά προβλήματα

- **Java not found / java is not recognized:** εγκαταστήστε Java και ανοίξτε νέο terminal· ελέγξτε PATH/JAVA_HOME.
- **UnsupportedClassVersionError:** χρησιμοποιείται Java παλαιότερη από 21. Ελέγξτε και το JAVA_HOME, όχι μόνο το `java -version` του PATH.
- **HeadlessException / Can't connect to X11:** τρέξτε από τοπικό γραφικό desktop με πλήρες desktop runtime.
- **Unable to access jarfile:** αποσυμπιέστε ολόκληρο το ZIP· αφήστε το JAR δίπλα στα scripts.
- **Permission denied στην αποθήκευση:** μεταφέρετε το πακέτο σε εγγράψιμο φάκελο του χρήστη, όχι σε προστατευμένο/system directory.
- **Δεν υπάρχουν ομάδες ενώ περιμένατε δεδομένα:** αντιγράψτε τον σωστό υποφάκελο `data` δίπλα στο JAR. Χρησιμοποιήστε τα scripts, που ορίζουν πάντα αυτόν τον φάκελο ως working directory.

## Δημιουργία του ZIP στον υπολογιστή ανάπτυξης

Μόνο ο δημιουργός του πακέτου χρειάζεται **JDK 21+, Maven 3.9+ και Python 3.9+**. Από το repository:

```sh
python3 scripts/package_release.py
```

Το script εκτελεί `mvn clean verify`, ελέγχει το executable JAR και τις βασικές ενσωματωμένες βιβλιοθήκες, δημιουργεί το ZIP και ένα SHA-256 αρχείο στο `dist/`. Χρησιμοποιεί ρητή λίστα αρχείων ώστε να αποκλείονται τα πραγματικά δεδομένα. Αν αλλάξουν οι εκδόσεις runtime dependencies, ενημερώστε και τη λίστα άδειών τους στο script.

Έλεγχος checksum μετά τη μεταφορά:

```sh
# Linux, στον φάκελο που περιέχει ZIP και .sha256
sha256sum -c managers-sidekick-0.9.0-test.zip.sha256
```

```powershell
# Windows PowerShell: συγκρίνετε το Hash με το περιεχόμενο του .sha256
Get-FileHash .\managers-sidekick-0.9.0-test.zip -Algorithm SHA256
```

Το εσωτερικό `SHA256SUMS.txt` περιέχει hashes των περιεχομένων. Τα hashes ελέγχουν ακεραιότητα μεταφοράς, δεν αποτελούν ψηφιακή υπογραφή.

## Έλεγχος στους υπολογιστές δοκιμής

Δοκιμάστε εκκίνηση, ελληνικά/κουμπιά, δημιουργία ομάδας και δεξιοτήτων, υπολογισμό με χειροκίνητες επιλογές, αποθήκευση και επανεκκίνηση, PDF με ελληνικά, αντίγραφο ομάδας και διαγραφή του αντιγράφου. Καταγράψτε OS, `java -version` και ακριβές μήνυμα σε περίπτωση σφάλματος.

Το πακέτο έχει δημιουργηθεί και ελεγχθεί στο macOS. Δεν έχει γίνει πραγματική εκτέλεση GUI σε Windows/Linux μέσα στο περιβάλλον ανάπτυξης· αυτή είναι η δοκιμή αποδοχής που θα γίνει στους δύο υπολογιστές.
