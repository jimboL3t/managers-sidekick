# Έλεγχοι έκδοσης 0.2.0

Εκτέλεση: `mvn clean verify`.

Αποτέλεσμα στις 29/09/2026: επιτυχές build και **18 δοκιμές**, 0 αποτυχίες, 0 σφάλματα, 0 παραλείψεις. Εκτελέσιμο: `target/managers-sidekick-0.2.0.jar`.

## Αυτοματοποιημένοι έλεγχοι

- Κάλυψη πόστων, διατήρηση κλειδωμένων επιλογών και μη δημιουργία επιπλέον ρεπό για πλεονάζον προσωπικό.
- Ανεπαρκείς δεξιότητες χωρίς μη επιτρεπόμενες αυτόματες αναθέσεις.
- Νυχτερινή ανάπαυση στο όριο μηνών, ακριβώς 11 ώρες ανάπαυσης και νυχτερινή βάρδια με ενδιάμεση ημερολογιακή ημέρα.
- Έξι συνεχόμενες εργάσιμες και κλειδωμένες επιλογές επόμενου μήνα.
- Μέτρηση πραγματικών Σαββάτων/Κυριακών, όρια μηνών και δίσεκτος Φεβρουάριος.
- Δύο αργίες δίνουν σε όλους 10 ρεπό, ακόμη και όταν μία είναι Σαββατοκύριακο.
- Κανονική κάλυψη αργιών, είτε ο εργαζόμενος έχει χειροκίνητα εργασία είτε ρεπό στην αργία.
- Έλλειψη προσωπικού επιστρέφει μερικό πρόγραμμα με σωστή μηνιαία ποσόστωση.
- Κανονική άδεια δεν μειώνει το δικαίωμα ρεπό.
- Αποθήκευση/επαναφόρτωση αργιών και συμβατότητα με JSON χωρίς πεδίο αργιών.
- JSON backup και απόρριψη κατεστραμμένου αρχείου.
- PDF με ελληνικά, οριζόντιο Α4 και σελιδοποίηση 12 εργαζομένων.
- Επεξεργασία κελιού αλλάζει μόνο το συγκεκριμένο κελί, χωρίς εξάρτηση από τον scheduler ή dialogs.
- Η επεξεργασία απαγορεύεται όσο υπολογίζεται το πρόγραμμα.
- Ο πραγματικός Swing πίνακας αποδίδει διακριτά χρώματα Σαββατοκύριακου/αργίας, κόκκινες ακάλυπτες ημερομηνίες και έτος `2026` χωρίς κόμμα.

Οι Swing δοκιμές εκτελούνται σε headless mode και παράγουν `target/calendar-preview.png` με τον ίδιο πίνακα και renderers που χρησιμοποιεί το GUI. Η εικόνα ελέγχθηκε οπτικά. Δεν είναι screenshot πλήρους desktop συνεδρίας.

## Χειροκίνητη αποδοχή GUI

Η πλήρης αλληλεπίδραση σε desktop και η πραγματική εκτύπωση δεν έχουν εκτελεστεί. Για επιβεβαίωση:

1. Δημιουργήστε δύο ομάδες με διαφορετικά πόστα, δεξιότητες και άδειες.
2. Επιλέξτε **Ερχόμενος μήνας**, δώστε χειροκίνητες επιλογές και επιβεβαιώστε ότι δεν εμφανίζεται popup ούτε αλλάζει άλλο κελί.
3. Δηλώστε δύο αργίες και ελέγξτε τον αυξημένο στόχο χωρίς μεταβολή των βαρδιών πριν τον υπολογισμό.
4. Πατήστε **Υπολογισμός βαρδιών** και επιβεβαιώστε κλειδωμένα κελιά, στόχους ρεπό και κόκκινες ημερομηνίες ελλιπούς κάλυψης.
5. Αλλάξτε μήνα/έτος, κλείστε και επανεκκινήστε για έλεγχο ιστορικού.
6. Προεπισκόπηση/εκτύπωση PDF με ελληνικά, μεγάλο όνομα, αργίες και πολλούς εργαζομένους.

Οι δοκιμές δεν εγγυώνται εύρεση λύσης για κάθε ομάδα. Οι κανόνες και οι περιορισμοί περιγράφονται στην τεχνική τεκμηρίωση.
