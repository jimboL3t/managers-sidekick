# Manager’s Sidekick — έκδοση 1.1.0

[English](START-HERE.en.md)

1. Εγκαταστήστε Java **21 ή νεότερη** για το λειτουργικό/αρχιτεκτονική σας. Αρκεί πλήρες desktop JRE· λειτουργεί και JDK. Δεν χρειάζεται Maven, Python ή IDE.
2. Κάντε εξαγωγή **όλου** του ZIP σε φάκελο του χρήστη σας. Μην εκτελείτε αρχεία μέσα από το ZIP.
3. Windows: διπλό κλικ στο `start-windows.cmd`.
4. macOS: από Terminal στον αποσυμπιεσμένο φάκελο εκτελέστε `sh start-linux.sh`.
5. Linux: μέσα στον αποσυμπιεσμένο φάκελο εκτελέστε `sh start-linux.sh` από terminal σε γραφικό desktop.

Αναλυτικές εγκαταστάσεις και αντιμετώπιση προβλημάτων: [docs/DISTRIBUTION.md](docs/DISTRIBUTION.md).
Οδηγίες χρήσης: [docs/ADMIN_GUIDE.md](docs/ADMIN_GUIDE.md).

Το πακέτο δεν περιλαμβάνει Java ή δεδομένα εργαζομένων. Ξεκινά με κενές ομάδες. Τα δεδομένα δημιουργούνται στον υποφάκελο `data` δίπλα στο JAR. Για δοκιμή με υπάρχον πρόγραμμα, ακολουθήστε τις οδηγίες μεταφοράς στο documentation.

Πριν από αναβάθμιση: Αποθήκευση, κλείσιμο εφαρμογής και αντίγραφο όλου του φακέλου `data`. [Αναλυτικές οδηγίες backup και επαναφοράς](docs/BACKUP.md).
